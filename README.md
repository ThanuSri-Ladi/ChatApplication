# 💬 Chat Application

A simple desktop-based Chat Application developed using **Java Swing**.  
This project is my first step toward building a complete real-time messaging application and will be continuously improved with additional features and technologies.

## 📌 Current Version

**Version 1.0 – Basic Chat Application**

The current version focuses on implementing the fundamental features of a messaging application using Java and file handling.

## ✨ Features

- 👤 User Registration
- 🔐 User Login
- 👥 Multiple User Support
- 💬 One-to-One Messaging
- 💾 Persistent User Data
- 💾 Persistent Chat Messages
- 🚪 Logout Functionality
- ⌨️ Send messages using the Enter key
- 🖥️ Simple Graphical User Interface

## 🛠️ Technologies Used

- **Java**
- **Java Swing**
- **Java AWT**
- **Object-Oriented Programming (OOP)**
- **Java File Handling**
- **Git & GitHub**
